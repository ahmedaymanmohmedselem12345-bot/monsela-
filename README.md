# MonSela

واجهة متجر مصرية عربية بالكامل، مبنية بـNext.js وReact وCSS variables. المجلد فيه الكود الكامل، والأصول، وإعدادات البناء، واختبارات منطق المتجر الأصلي. الكتالوج الحقيقي بيتحمّل من مشروع Supabase. لو جدول المنتجات مفيهوش عناصر نشطة، الواجهة بتعرض حالة المتجر الفاضي من غير منتجات وهمية.

## التشغيل

استخدم Node.js 22 أو أحدث.

```sh
npm ci
npm run dev
```

للتأكد من بناء الإنتاج محليًا:

```sh
npm test
npm run build
npm start
```

البناء الثابت في `out/`. إعداد Vercel موجود في `vercel.json`. استخدم رابط Preview للمراجعة الأول. الإعداد الافتراضي هو عنوان المشروع والمفتاح العلني الموجودين في نسخة مونسيلا الأصلية. لو هتستخدم مشروع اختبار، انسخ `.env.example` إلى `.env.local` واضبط **العنوان والمفتاح العلني مع بعض**. لإعداد Vercel، ضيف نفس المتغيرات في بيئة Preview. القيم العلنية بتدخل في ملفات المتصفح وقت البناء.

في Supabase اسمح بإعادة التوجيه إلى أصل الموقع لمسار التسجيل مثل `https://shop.example/`، وإلى `/reset-password.html` لاستعادة كلمة المرور. النسخة بتستخدم مخطط مونسيلا الموجود ودواله، ومن ضمنها `place_order` و`validate_coupon` و`track_order_logged`. تأكيد حساب المالك، صلاحيات RLS وإرسال رسائل الاستعادة محتاجين مراجعة على مشروعك قبل الإطلاق. ملفا SQL المرفقان من المشروع الحالي وهما خارج مجلد النشر.

## ملفات الواجهة

| الملف | دوره والتغيير |
|---|---|
| `app/layout.jsx` | رأس الموقع وإعداد العربية RTL وsafe area. الخطوط العربية واللاتينية محلية ضمن بناء Next لتقليل الاعتماد على طلبات خارجية. |
| `app/page.jsx` | نقطة الدخول للواجهة الجديدة. |
| `app/globals.css` | الألوان والدرجات المشتقة، المكونات، حالات التركيز، الحواف الآمنة، والحركة القصيرة. نقاط الفصل 768 و1025 بكسل. شبكة المنتجات عمودان على الموبايل بفاصل 12 بكسل، ثم ثلاثة وأربعة. |
| `components/Storefront.jsx` | ينسّق حالة الكتالوج والحساب والنوافذ والسلة وأحداث المتجر. السلة والعناصر المحفوظة تستخدم مفاتيح التخزين القديمة. |
| `components/Button.jsx` | زر ورابط بنفس نظام الألوان ومساحة الضغط وحلقة التركيز. |
| `components/Header.jsx` | الكحلي ثابت مع ظل عند التمرير. اللوجو في المنتصف على الموبايل، وفي أول الهيدر على الشاشات الواسعة، مع قوائم الأقسام والحساب والسلة والتتبع. |
| `components/NavDrawer.jsx` | قائمة من ناحية اليمين مع الأقسام والتتبع، والحساب والسلة في الأسفل. |
| `components/BottomNav.jsx` | أربع وجهات مع تمييز نشط ذهبي. اختير للتابلت الطولي عشان يفضل الهيدر خفيف وسهل الوصول. التابلت العرضي يستخدم قائمة سطح المكتب بمسافات أقل. |
| `components/Dialog.jsx` | أساس النوافذ والقوائم. يحصر التركيز ويرجعه للزر عند الإغلاق، ويدعم Escape ولوحة المفاتيح، مع مقاسات كاملة على الموبايل وألواح جانبية على التابلت. |
| `components/Hero.jsx` | صورة حملة توضيحية من `next/image` بارتفاع محجوز وبديل مصمم. ترتيب الصورة أولًا والزر بعرض كامل على الموبايل. استبدل `public/assets/monsela-hero.webp` بصورة العلامة النهائية عند تجهيزها. |
| `components/FloatingButtons.jsx` | واتساب والرجوع لأول الصفحة في الحافة اليسرى. الأزرار تختفي وقت ظهور النوافذ وقرب الاشتراك والفوتر. |
| `components/FAQ.jsx` | أسئلة قابلة للفتح بالنقر والكيبورد، بخط Tajawal وسهم رابط متجه لليسار. |
| `components/Newsletter.jsx` | نموذج رقم موبايل مصري مع سبب الاستخدام وحالة الإرسال، مرتبط بجدول `newsletter_subscribers` الحالي. |
| `components/Footer.jsx` | روابط المتجر والمساعدة والشركة والسوشيال، وصف الثقة، وحقوق النشر. |
| `components/LoginForm.jsx` | البريد للحسابات الجديدة، ويدعم دخول الحسابات القديمة برقم الموبايل. يشمل التسجيل وإرسال رابط الاستعادة وعلاج لون الملء التلقائي في CSS. |
| `components/CartDrawer.jsx` | السلة الفاضية والسلة المليانة، تعديل الكمية والحذف والحفظ لبعدين، وزر إتمام الطلب في تذييل ثابت داخل اللوحة. |
| `components/EmptyProductState.jsx` | حالات منفصلة للتحميل، الكتالوج الفاضي، الفلاتر بلا نتائج، وعطل التحميل مع إعادة المحاولة. |
| `components/ProductArea.jsx` | أقسام قابلة للتمرير وبحث وبطاقات المنتج، مع تحميل الصور تحت الطية عند الحاجة. |
| `components/ProductDetails.jsx` | عرض المنتج والمقاس واللون والكمية، وتجهيز طلب الإضافة طبقًا لقواعد المخزون الحالية، مع رابط التفاصيل والتقييمات الأصلية. |
| `components/FilterSheet.jsx` | الترتيب والفلاتر في لوحة سفلية على الموبايل ولوحة جانبية على التابلت، مع تطبيق ومسح. |
| `components/CheckoutForm.jsx` | الطلب كضيف أو بحساب، الشحن والكوبون والهدية وطرق الدفع المفعلة. يعيد جلب البيانات قبل الإرسال ويحافظ على عقد الدالة `place_order`. |
| `components/OrderTracking.jsx` | تتبّع برقم الطلب والموبايل، وعرض الحالة ومراحلها والدفع وميعاد الوصول لو موجود. |
| `components/ScentQuiz.jsx` | عرض اختبار العطور القديم بتفاعل جديد، ويحتفظ بالنتيجة على الجهاز. |

## الربط والملفات المساندة

| الملف | دوره |
|---|---|
| `lib/brand.js` | أسماء الأقسام وربطها بتسميات الكتالوج وروابط التواصل وتنسيق الجنيه. |
| `lib/catalog.js` | فلاتر بيانات الكتالوج المطابقة للحقول الحالية، والبحث متعدد الكلمات وخيارات الترتيب. |
| `lib/checkout.js` | قراءة بيانات الشحن والدفع والمنتجات والتحقق من الكوبون بعقد Supabase الحالي. |
| `lib/quiz.js` | أسئلة ونظام النقاط من النسخة الأصلية. |
| `lib/supabase.js` | عميل Supabase مشترك ومهلة الاتصال الموجودة في مشروع مونسيلا. |
| `lib/supabase-defaults.json` و`lib/public-config.json` | الأول لقيم الاتصال العلنية الافتراضية، والثاني ناتج قابل لإعادة التوليد من متغيرات البيئة. |
| `scripts/sync-public-config.mjs` | يوحّد إعدادات الواجهة الجديدة والصفحات الأصلية ويمنع استخدام مفتاح غير علني في حزمة المتصفح. |
| `scripts/dev.mjs` | يشغّل Next محليًا، ويمرر إعدادات العنوان والمنفذ إلى CLI. |
| `next.config.mjs` و`jsconfig.json` | إعداد التصدير الثابت وأسماء مسارات الاستيراد. |
| `package.json` و`package-lock.json` | أوامر التشغيل واعتمادات بإصدارات قابلة لإعادة التثبيت. |
| `vercel.json` | مسار ناتج البناء وإعدادات ترويسات الوصول للصفحات. |
| `public/assets/store-core.js` | منطق مونسيلا الحالي لحساب الأسعار والشحن، تطبيع الموبايل، واختيارات المنتج والمخزون. يتشاركه المتجر الجديد والأصلي. |
| `public/original/index.html` و`public/assets/original-entry.js` | يحتفظان بالوصول للوظائف الموسعة من روابط الواجهة الجديدة، مثل حسابي الكامل وتقييمات المنتجات والهدايا والمفضلة والمقارنة. صفحات الوظائف دي بتستخدم قالبها الأصلي. |
| `public/admin.html` و`public/reset-password.html` | لوحة الإدارة الحالية وإكمال استعادة كلمة المرور، مع نفس إعداد مشروع Supabase المستخدم في الواجهة الجديدة. |
| `public/about.html` و`public/contact.html` و`public/faq.html` وصفحات السياسات | محتوى الصفحات من المتجر الحالي، مع توجيه روابط الرجوع للواجهة الجديدة. |
| `database/` | فحص تعريفات قاعدة البيانات وإعداد صلاحية المالك من النسخة الأصلية. تشغيلها يدوي داخل المشروع المناسب. |
| `tests/` | اختبارات مونسيلا الحالية للحسابات والمخزون، ومحاكاة الدفع وصلاحيات لوحة الإدارة. |

## تحقق قبل الإطلاق

- اتختبر المتجر في Chromium عند عروض 360 و390 و900 و1000 و1024 و1280 بكسل. شملت التجربة الشرايح والفلاتر وحالات الكتالوج الفاضي والخطأ، التنقل وحصر التركيز، نموذج الدخول والاختبار. 
- اختبار المتصفح لإتمام الطلب استخدم خادم محاكاة محلي للتحقق من الطلب كضيف والكوبون وإيصال الطلب والتتبع. بيانات المحاكاة خارج الحزمة.
- تأكد على بيئة Supabase التجريبية من ظهور الطلب في الإدارة وخصم المخزون وتغيير الحالة وإرسال بريد الاستعادة. الحماية من طلب مكرر عبر أكثر من تبويب تعتمد على دالة الخادم. مسار التحويل اليدوي الحالي يسجل بيانات التحويل للمراجعة.
